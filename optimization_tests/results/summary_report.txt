KEY OBSERVATIONS
--------------------------------------------------------------------

1. O0 (No optimization):
   - Baseline for comparison
   - Largest code size
   - Slowest execution

2. O1 (Basic optimizations):
   - Dead code elimination
   - Simple strength reduction
   - Moderate improvements

3. O2 (Recommended):
   - All O1 plus:
   - Loop unrolling
   - Function inlining
   - CSE and constant propagation
   - Best balance of speed and size

4. O3 (Aggressive):
   - All O2 plus more aggressive optimizations
   - May increase code size
   - Diminishing returns in some cases

5. Os (Size optimization):
   - Optimizes for smallest code size
   - Disables optimizations that increase size
